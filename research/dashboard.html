💡 Входящие идеи — копилка

  • OECD average wages — реальная avg зарплата для стран OECD (предусловие для будущего платного отчёта). → повышено в план #5
  • Внутренний «house-ad» слот — промо наших же фич (финдер / калькулятор / гайд / хаб), ротация по неделям (ISO-week), лента «Featured on CostTrek». Гонит внутренний трафик на свежее + перелинковка. Дёшево; хороший быстрый инсерт.
  • Миграция на Cloudflare (спайк) — через @opennextjs/cloudflare. НЕ сейчас (трафик ≈0, Vercel уже оптимизирован). Статику CF отдаёт бесплатно → «больше страниц» = вопрос file-лимита (free 20k / paid 100k ассетов), а не счёта; у нас ~25–35k файлов → нужен paid ($5/мес).
  • Самоописания сети — блоки по шаблону для обзоров на foundaday. → часть плана #2
  • ISR для region/persona-хабов — снять давление потолка Vercel и build-минут при росте городов.
  • i18n-ярлыки метрик — в metrics.ts сейчас EN на всех локалях.
  • Локализованные URL-слаги (/de/vergleich/…) — лучше для SEO, но нужны per-locale маршруты.
  • support@ / hello@ алиасы в Cloudflare — ловить частые угаданные адреса (catch-all выключен).
  • Форма фидбэка вместо mailto — только если пойдёт объём обращений.
  • GSC-гигиена — ~10 ценных URL/день вручную, пока индексация догоняет.

Стоящие фоном

Мониторим, не отдельные запуски:
  • Обвал показов −99% — вероятно норма молодого домена, прод здоров; не передебажывать каждый заход.
  • AdSense readiness — структурно готово, ждём порог трафика (трекается централизованно в izn.project.stats).
  • RUM/Cloudflare — домен не проксирован, edge-аналитика пустая, только RUM-beacon.
  • Флаг TRAVELPAYOUTS_DRIVE = true → выключить перед AdSense-ревью.
