## Очередь

Порядок = приоритет (не дата). Код-рычаги по SEO в основном исчерпаны — узкое место
теперь **авторитет + время + монетизация**, поэтому верх очереди — действия владельца,
а не код.

**Режим исполнения** (кто дешевле по токенам владельца): `→cursor` — механика/объём
однотипного письма; я пишу промт + **спот-чек** (выборка + сборка), не полное ревью.
`→сам` — трудно *решить что делать* (судейские решения по данным, контент = продукт,
завязка на наш нестандартный стек/конвенции). `→гибрид` — решение + каркас + первый
образец за мной, тираж по образцу — Cursor. **owner-side** — не код (действие владельца),
ни Cursor, ни чат. Глубина проверки: `→cursor` — спот-чек; `→сам` / рискованное — полное ревью.

## Заметки

**Где мы сейчас.** Продукт зрелый: ~87 городов, ~34 страны, ~11.9k страниц, 5 языков,
travel-magazine дизайн, полный тех-SEO, финдер, калькуляторы, ранкинг-хабы, гайды, legal.
Трафик ≈ 0 (10–20 pv/день), показы в GSC растут но клики ≈0, позиции 6–10. Вывод:
ширина (ещё города/хабы) больше НЕ рычаг — новые страницы падают в «discovered, not
indexed». Наверх → бэклинки (дефицит #1), глубина по доказанным кластерам, траст/данные.

**Доказанные кластеры спроса (GSC/Bing):** Singapore (сильнейший), «digital nomad visa»
(79), «is japan cheaper than india» (34), «cost of living charlotte nc» (42), «tax relief
for new residents» (20). Страницы под них ЕСТЬ — вопрос глубины и авторитета, не покрытия.

**Принципы (не менять без причины).** Органика только; углублять, а не расширять; данные
реальные > оценок. Приём денег: KG ИП — Payoneer/крипта/Wise/банк, PayPal не принимает.
Деплой: `git push` в `main` → CI → Cloudflare (ручной `cf:deploy` не нужен). Другие сессии
тоже пушат — при старте быстрый `git log`/tsc-чек.

**Стоящие фоном (мониторим, не отдельные запуски).**
- Обвал показов 28д −99% — вероятно норма молодого домена + честный алго-settle; прод
  здоров, не переразбирать каждый запуск (сам разбор/решение — в Очереди #4).
- Googlebot-краул после CF (8/нед vs 1808 AppleBot) — серверная диагностика чиста
  (robots Allow, sitemap 200, Googlebot-UA 200, Under Attack off); вероятно пост-миграционная
  осторожность + плато молодого домена. Настоящий сигнал — GSC Host status после 05.10.
- AdSense readiness — структурно готово; ждём порог трафика (трекается в izn.project.stats).
- RUM/Cloudflare аналитика — домен не проксирован, edge-аналитика пустая, только RUM-beacon
  (см. память `costtrek-analytics-limits`).
- Флаг `TRAVELPAYOUTS_DRIVE = true` — выключить перед AdSense-ревью.

**НЕ делаем (ров конкурентов / нет данных / против принципов).** Крауд-цены и охват
